# Esta es una aplicación de demostración construida con React y Vite.
 Permite a los usuarios visualizar, crear, actualizar y eliminar productos (operaciones CRUD). Tecnologías Principales
 pincipal para construir la interfaz de usuario.
 Vite Herramienta de construcción rápida para el entorno de desarrollo.
 Tailwind CSSFramework CSS para un diseño rápido y responsivo.
 AxiosCliente HTTP para manejar la comunicación con la API externa (MockAPI).
 React ToastifyPara notificaciones de éxito/error (e.g., al crear o eliminar un ítem).
 React Router DOMPara la navegación y manejo de rutas (Catálogo, Crear, Editar, Detalle).
